# AI Agent 与集成

把模型接进真实系统，难点基本不在模型，而在工具边界、状态管理和错误兜底。

## 这个板块写什么

- [Agent 的三层结构](./agent-arch.md) —— 模型、工具、编排各自该负责什么
- [飞书机器人接 Agent](./feishu-bot.md) —— 一条消息从进入到回复的完整链路
- [MCP 为什么值得用](./mcp.md) —— 工具调用需要一个标准协议的理由

## 一个前提判断

实际排查下来，"Agent 不好用"里绝大多数是这三类问题：工具描述写得含糊、返回值没有约束、失败没有兜底。模型本身很少是真正的瓶颈。

所以这里的文章重心在工程约束，不在提示词技巧。
