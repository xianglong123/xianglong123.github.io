## 这个站是什么

一个技术笔记的归档站，不是教程站。主体是 Java 生态：基础、集合、并发、JVM、IO，加上日常绕不开的 MyBatis、JPA、MySQL。一百来篇，都是自己写代码、排故障时留下来的东西。

每个板块的第一篇是体系总览，先看它能把脉络串起来；后面再进具体实现和源码分析。大部分文章里都有从问题出发的排查过程——这类内容在文档里查不到。

## 我是谁

七年 Java，做过业务线技术负责人和架构师，在北京待了七八年。现在在重庆，主要精力放在独立开发上：做工具站、写小产品，顺带把这些年攒下的东西整理归档。

没什么宏大的目标，就是把踩过的坑写下来，下次不用重新踩一遍。
