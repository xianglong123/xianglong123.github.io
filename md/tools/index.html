工具站开发 ​

工具站是一类很特别的站点：没有用户系统，没有数据库，没有留存，但必须"能信"。用户点进来就是为了拿一个结果，然后走。

这个板块写什么 ​

  • 国密 SM2 / SM4 在纯前端怎么做 —— 计算放浏览器，服务端零存储
  • 用 GitHub Actions + Pages 做数据站 —— 零成本的定期数据发布

这类站的三个设计约束 ​

  1. 计算能放前端就放前端 —— 省服务器，更重要的是：数据不出浏览器，"用完即走"这件事在技术上真的成立，不只是文案。
  2. 结果必须可验证 —— 加密/解密、格式转换这类工具，用户没法直观判断对不对。给出中间值、提供正反验证，比给一个漂亮界面重要。
  3. 不要攒数据 —— 一旦存了用户输入，就要承担存储安全和合规责任。不存，是这类站最便宜的护城河。
